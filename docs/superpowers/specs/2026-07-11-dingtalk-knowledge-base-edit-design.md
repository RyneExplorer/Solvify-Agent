# 钉钉同步知识库编辑交互设计

## 目标

钉钉同步知识库卡片与本地知识库共用编辑入口，不再展示“查看”按钮。

## 交互

- 钉钉同步知识库操作项依次为“编辑”“刷新目录”“删除”
- 点击“编辑”打开现有知识库编辑弹窗
- 编辑范围沿用现有字段：名称、分类、描述
- 卡片空白处仍跳转到对应文档库
- 刷新目录和删除行为保持不变
- 其他来源知识库卡片保持现状

## 实现范围

- `KBCard.vue` 为钉钉同步知识库显示编辑按钮并隐藏查看按钮
- `KnowledgeBasePage.vue` 将钉钉卡片的编辑事件绑定到现有 `openEdit` 流程
- 不新增接口、弹窗或数据结构

## 验证

- 钉钉同步知识库卡片不再显示“查看”
- 点击“编辑”可打开并保存现有编辑弹窗
- 点击“刷新目录”“删除”和卡片空白处仍执行原有行为
- 前端生产构建通过
