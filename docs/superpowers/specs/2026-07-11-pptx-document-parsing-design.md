# PPTX 文档解析设计

## 目标

在现有 DOCX、PDF 文档解析链路上补充 PPTX 文件支持，使 PPTX 上传后可以提取正文、生成文档版本、切块并进入现有 RAG 检索流程。同时为 PDF 和 DOCX 提供原始文件在线预览

## 范围

- 支持 `.pptx` 文件上传和自动解析
- 按幻灯片提取标题、正文、列表和表格
- 将提取结果转换为 Markdown 风格文本，用于在线编辑和预览
- 使用归一化文本执行切块、向量化和检索入库
- 同步更新前端支持类型提示、文件类型展示和项目文档
- PDF 使用浏览器原生能力在线预览
- DOCX 使用 `docx-preview` 在前端预览
- PPTX 显示暂不支持在线预览，并保留原文件下载入口

以下内容不在本次范围：

- 旧版 `.ppt` 文件
- 幻灯片版式、图片、音频、视频、动画和备注解析
- PPTX 文件在线预览
- DOCX 复杂字体、浮动元素和分页效果的完全保真还原

## 方案

Python 解析脚本使用 `python-pptx` 读取 PPTX。每页以 Markdown 标题标识页码，依次提取文本框中的段落和表格内容；列表转换为 Markdown 列表，表格转换为 Markdown 表格

Go 文本提取器继续作为统一入口，将 PPTX 交给 Python 脚本处理。文档服务复用现有处理流程：展示正文保存到 `document_versions.content`，归一化后的正文用于生成 `document_chunks`

原始文件预览复用现有鉴权接口返回 Blob。PDF Blob 通过 `iframe` 展示；DOCX Blob 由 `docx-preview` 渲染到预览弹窗容器；PPTX 不进行渲染，只展示不支持提示和下载入口

## 数据流

1. 前端选择 PPTX 并调用现有文档上传接口
2. 后端校验扩展名、文件大小、同名文档和存储配额
3. 异步处理任务调用统一文本提取器
4. Python 脚本按幻灯片输出 Markdown 风格正文
5. 后端保存展示正文，并对检索正文执行归一化、切块和向量化
6. 文档状态更新为处理成功或处理失败，前端沿用现有轮询显示结果

## 错误处理

- 未安装 `python-pptx` 时返回明确的中文依赖缺失错误
- PPTX 损坏、加密或未提取到文本时沿用现有文档处理失败状态
- DOCX 预览加载或渲染失败时在弹窗中展示中文错误
- 不增加数据库字段，也不引入 LibreOffice 等后端转换依赖

## 验证

- Python 脚本语法检查
- 使用含标题、正文、列表和表格的 PPTX 样例验证输出结构
- 运行 `go test ./...`
- 运行 Vue 前端构建
- 手动检查 PDF、DOCX、PPTX 三类文件的预览分支
- 检查最终 diff，确认未包含 `.ppt` 支持和 PPTX 在线渲染
