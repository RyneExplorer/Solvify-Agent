# 文本文档在线预览修复设计

## 目标

修复本地知识库纯文本文档打开“查看原文”后内容空白的问题。

## 文件类型

- PDF：继续使用浏览器内置预览
- DOCX：继续使用 `docx-preview`
- Markdown（md、markdown）：读取 Blob 文本并渲染为格式化 HTML
- TXT：读取 Blob 文本并以转义后的源码文本展示
- HTML：读取 Blob 文本并以转义后的源码文本展示，不执行其中的标签和脚本
- JSON：解析后格式化缩进并以专用代码视图展示
- CSV：解析后以专用表格展示
- 图片和其他文件：保持现有行为

## 安全

- Markdown 渲染前转义原始 HTML 标签，避免执行上传内容中的脚本
- TXT 和 HTML 使用转义后的 `pre` 文本展示
- 不直接把上传的 HTML 注入页面
- JSON 和 CSV 解析失败时显示明确错误，不回退为空白内容

## 验证

- Markdown 可以显示标题、段落、列表和代码块
- TXT 和 HTML 源码可见且不会执行标签
- JSON 可以格式化展示，CSV 可以按表格展示
- PDF、DOCX 和图片预览不受影响
- 关闭预览后清理文本和 Blob URL
- 前端生产构建通过
