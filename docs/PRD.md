# Solvify-Agent 企业级知识管理系统 PRD

## 1. 项目背景

Solvify-Agent 是一个基于大语言模型的知识管理框架，旨在解决企业文档分散、知识检索效率低、智能问答能力不足等问题。通过 RAG 技术和 Agent 编排，将分散的文档沉淀为可查询、可推理、可持续演进的专属知识资产。

---

## 2. 产品目标

**解决的问题：**
- 企业文档分散在多个系统，查找困难
- 传统搜索无法理解语义，检索精度低
- 缺乏基于企业知识的智能问答能力

**目标用户：**
- 企业知识工作者（日常查询、学习）
- 客服人员（快速回答客户问题）
- 管理员（系统配置、用户管理）

**成功标准：**
- 知识库检索召回率 ≥ 85%
- 问答响应时间 ≤ 3 秒
- 支持 10GB 知识库存储
- 支持 100+ 并发用户

---

## 3. 用户角色

| 角色 | 描述 | 权限范围 |
|------|------|----------|
| 超级管理员 | 系统最高权限用户 | 所有功能权限 |
| 管理员 | 被授权的管理用户 | 用户管理、知识库管理、会话管理 |
| 编辑者 | 知识内容管理者 | 知识库创建、文档上传、内容编辑 |
| 观察者 | 只读用户 | 查看知识库、查看会话记录 |

**权限分配规则：**
- 超级管理员在系统初始化时自动创建
- 超级管理员可以分配其他角色的权限

---

## 4. 用户场景

**场景1：智能问答**
用户选择知识库和搜索模式，输入问题，系统基于 RAG 检索知识库并结合联网搜索生成回答，用户可将优质回答加入知识库。

**场景2：知识库管理**
用户创建知识库分类，上传文档，系统自动解析、向量化并建立索引，用户可对文档进行增删改查和转移操作。

**场景3：系统配置**
用户可配置个人使用的 AI 模型和搜索工具（需自己的 API Key），系统验证配置有效性后生效。管理员可配置系统级默认模型、向量数据库和集成工具。

**场景4：后台管理**
管理员查看用户列表、会话记录、系统日志，进行用户状态管理、会话清理和异常排查。

## 5. 功能需求

### FR-001 用户注册与登录

用户通过邮箱/手机号注册账号，登录后获得访问权限。

### FR-002 用户角色管理

超级管理员创建角色、分配权限，将角色分配给用户。

### FR-003 知识库创建

用户创建知识库，设置名称、分类、描述和存储配额。单用户总配额不超过 10GB。

### FR-004 文档上传与处理

用户上传文档到知识库，系统自动解析、分块、向量化并建立索引。支持 PDF/Word/Txt/Markdown/HTML/CSV/Excel/PPT/JSON/图片格式，单文件不超过 100MB。

### FR-005 智能问答

用户输入问题，系统基于知识库和联网搜索生成回答。支持三种搜索模式：仅知识库、仅联网、混合模式。回答标注来源（蓝色：知识库，绿色：网络）。

### FR-006 ReAct Agent 多步推理

对于复杂问题，Agent 自动编排多步推理流程，调用知识检索、工具和网络搜索，逐步得出答案。

### FR-007 Wiki 模式

Agent 驱动从原始文档自动生成结构化、相互链接的 Markdown Wiki 知识页面，并生成知识图谱。

### FR-008 文档在线编辑

用户在线编辑知识库中的文档内容，系统记录编辑历史并重新向量化。

### FR-009 多源数据导入

支持从飞书、Notion、钉钉等平台导入知识库，支持全量和增量同步。

### FR-010 模型配置管理

用户可配置个人使用的 AI 模型，包括免费模型和自定义模型（需配置自己的 API Key）。管理员可配置系统级默认模型。

### FR-011 向量数据库配置

管理员配置向量数据库，支持 PostgreSQL/Elasticsearch/Milvus 等引擎。向量数据库配置为系统级设置，普通用户无需感知。

### FR-012 搜索工具配置

用户可配置个人使用的搜索工具（DuckDuckGo/Bing/Tavily/百度等），需配置自己的 API Key。管理员可配置系统级默认搜索工具。

### FR-013 钉钉集成

管理员配置钉钉 Webhook，实现知识库自动同步。需企业认证。

### FR-014 会话管理

用户查看、搜索、删除、重命名历史会话，支持在历史会话基础上继续提问。

### FR-015 后台管理

管理员进行用户管理、会话管理、知识库管理、日志管理和配置管理。

### FR-016 推荐问题生成

基于知识库内容自动生成推荐问题，帮助用户快速获取信息。

## 6. 业务规则

**BR-001** 用户总知识库容量不超过 10GB，单文件大小不超过 100MB。

**BR-002** 免费用户每月 AI 调用次数限制为 100 次，超出后需配置自定义模型。

**BR-003** 文档处理状态必须为"已就绪"才能参与检索。

**BR-004** 多租户数据完全隔离，不同租户的数据不可互相访问。

**BR-005** 超级管理员角色不可删除，不可修改权限。

**BR-006** 文档删除后保留 30 天，超过 30 天自动清理。

**BR-007** 会话记录保留 90 天，超过 90 天自动归档。

**BR-008** 联网搜索功能需用户自行配置 API Key。

**BR-009** 钉钉集成需企业认证，个人用户无法使用。

---

## 7. 边界条件

**空数据处理：**
- 知识库为空时，提示用户上传文档
- 搜索结果为空时，建议用户调整搜索词或开启联网搜索或模型自主回复要避免幻觉发生

**重复提交处理：**
- 文档上传支持幂等性，相同文件名覆盖旧文件
- 问答请求支持去重，1 秒内相同问题返回缓存结果

**网络异常处理：**
- 联网搜索失败时，降级为仅知识库模式
- LLM 调用超时时，返回部分结果并提示

**权限不足处理：**
- 无权限访问时，返回 403 错误
- 操作他人资源时，返回权限不足提示

**数据超限处理：**
- 存储空间不足时，提示用户清理或扩容
- 调用次数超限时，提示用户等待或升级

## 8. 非功能需求

### 性能
- 问答响应时间 ≤ 3 秒（不含 LLM 生成时间）
- 文档上传处理时间 ≤ 5 分钟（100MB 文件）
- 支持 100+ 并发用户
- 知识库检索召回率 ≥ 85%

### 安全
- 用户密码加密存储
- API 通信使用 HTTPS 加密
- 敏感配置加密存储
- 多租户数据完全隔离

### 可用性
- 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- 最小支持分辨率 1024x768
- 提供中文界面

### 日志记录
- 记录所有 API 请求日志
- 记录所有业务操作日志
- 记录所有错误日志
- 日志支持按时间、级别、模块筛选

## 9. 验收标准

### AC-001 用户注册
**Given** 用户访问注册页面
**When** 输入有效邮箱和密码
**Then** 系统创建账号并返回成功提示

### AC-002 知识库创建
**Given** 用户已登录且有编辑权限
**When** 输入知识库名称和描述
**Then** 系统创建知识库并返回知识库 ID

### AC-003 文档上传
**Given** 用户已登录且有编辑权限
**When** 上传 PDF 文件到知识库
**Then** 系统返回文档 ID，状态为"处理中"
**And** 处理完成后状态变为"已就绪"

### AC-004 智能问答
**Given** 用户已登录，知识库已有文档
**When** 输入问题并选择"混合"搜索模式
**Then** 系统返回回答，包含来源标注

### AC-005 权限控制
**Given** 用户角色为"观察者"
**When** 尝试上传文档
**Then** 系统返回权限不足错误

### AC-006 多租户隔离
**Given** 租户 A 和租户 B
**When** 租户 A 的用户查询知识库
**Then** 只能看到租户 A 的数据

### AC-007 存储配额
**Given** 用户已使用 9.5GB 存储
**When** 上传 1GB 文件
**Then** 系统返回空间不足错误

### AC-008 免费调用限制
**Given** 免费用户已使用 100 次调用
**When** 再次发起问答
**Then** 系统返回调用次数超限提示

## 10. 技术可行性说明

**需要关注的问题：**

1. **钉钉集成**：需要企业认证，建议先实现手动触发同步
2. **多租户隔离**：增加架构复杂度，建议初期使用 Schema 隔离
3. **免费调用限制**：需要分布式计数器，建议使用 Redis
4. **Wiki 模式**：实现难度较高，建议初期实现基础版本

**技术可行性确认：**

1. RAG 检索：成熟方案，Eino 框架已支持
2. ReAct Agent：Eino 框架支持 Agent 编排
3. 多模型支持：通过统一接口封装
4. 多格式文档解析：使用 Apache Tika 或类似工具
