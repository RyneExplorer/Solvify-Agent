# Solvify-Agent 企业级知识管理系统 PRD

## 1. 项目背景

Solvify-Agent 是一个基于大语言模型的知识管理框架，旨在解决企业文档分散、知识检索效率低、智能问答能力不足等问题。通过 RAG 技术和 Agent 编排，将分散的文档沉淀为可查询、可推理、可持续演进的专属知识资产。

---

## 2. 产品目标

**解决的问题：**
- 企业文档分散在多个系统，查找困难
- 传统搜索无法理解语义，检索精度低
- 缺乏基于企业知识的智能问答能力

**目标用户：**
- 企业知识工作者（日常查询、学习）
- 客服人员（快速回答客户问题）
- 管理员（系统配置、用户管理）

**成功标准：**
- 知识库检索召回率 ≥ 85%
- 问答响应时间 ≤ 3 秒
- 支持 10GB 知识库存储
- 支持 100+ 并发用户

---

## 3. 用户角色

| 角色 | 描述 | 权限范围 |
|------|------|----------|
| 超级管理员 | 系统最高权限用户 | 所有功能权限 |
| 管理员 | 被授权的管理用户 | 用户管理、知识库管理、会话管理 |
| 编辑者 | 知识内容管理者 | 知识库创建、文档上传、内容编辑 |
| 观察者 | 只读用户 | 查看知识库、查看会话记录 |

**权限分配规则：**
- 超级管理员在系统初始化时自动创建
- 超级管理员可以分配其他角色的权限

---

## 4. 用户场景

**场景1：智能问答**
用户选择知识库和检索模式，输入问题，系统基于 RAG 检索知识库生成回答。快速检索模式直接返回知识库结果；深度模式理解上下文进行检索，若知识库无结果则保底联网搜索（需配置搜索工具 API Key，未配置则不可用）。

**场景2：知识库管理**
用户创建自建知识库，上传文档，系统自动解析、向量化并建立索引。用户也可从钉钉、飞书、Notion 等平台同步知识库，同步知识库为只读，由系统自动维护。联网搜索知识库由系统自动创建，用户可将问答中的搜索结果保存到此知识库供后续使用。

**场景3：系统配置**
用户可配置个人使用的 AI 模型（需自己的 API Key）和搜索工具 API Key，系统验证配置有效性后生效。向量数据库仅管理员可配置，用户在系统状态页可查看当前使用的引擎。管理员可配置系统级默认模型、向量数据库和第三方平台集成。

**场景4：后台管理**
管理员查看用户列表、会话记录、系统日志，进行用户状态管理、会话清理和异常排查。

## 5. 功能需求

### FR-001 用户注册与登录

用户通过邮箱/手机号注册账号，登录后获得访问权限。

### FR-002 用户角色管理

超级管理员创建角色、分配权限，将角色分配给用户。

### FR-003 知识库创建

知识库分为三种来源类型：

| 来源类型 | 说明 | 操作权限 |
|----------|------|----------|
| 自建知识库 | 用户手动创建，上传文档 | 完全控制：增删改查、文档管理 |
| 同步知识库 | 从钉钉/飞书/Notion 等平台同步 | 只读：不可编辑文档，仅可查看和使用 |
| 联网搜索知识库 | 保存联网搜索结果 | 只读：由搜索结果自动生成 |

**自建知识库：** 用户设置名称、分类、描述，系统分配存储配额。单用户总配额不超过 10GB。

**同步知识库：** 由管理员配置集成平台后自动创建或由用户触发同步。同步知识库显示来源平台标识，文档内容由平台侧维护，系统定期增量同步。用户不可手动上传、编辑或删除同步知识库中的文档。

**联网搜索知识库：** 系统自动创建，用户可将问答中的搜索结果保存到此知识库供后续检索使用。

### FR-004 文档上传与处理

用户上传文档到知识库，系统自动解析、分块、向量化并建立索引。支持 PDF/Word/Txt/Markdown/HTML/CSV/Excel/PPT/JSON/图片格式，单文件不超过 100MB。

### FR-005 智能问答

用户输入问题，系统基于知识库检索或联网搜索生成回答。

**问答界面配置栏：**
- 知识库选择：下拉框选择要查询的知识库（默认全部）
- 检索模式：下拉框选择（快速检索 / 深度模式）
- 模型选择：下拉框选择已配置的模型（系统默认 + 用户自定义）

**检索模式说明：**

| 模式 | 说明 | 前置条件 | 适用场景 |
|------|------|----------|----------|
| 快速检索 | 直接检索知识库，返回最相关结果 | 无 | 简单问题、明确答案 |
| 深度模式 | 理解上下文进行多轮检索，若知识库无结果则保底联网搜索 | 必须配置搜索工具 API Key | 复杂问题、需要综合分析 |

**快速检索：**
- 直接使用 BM25 + Dense 向量检索知识库
- 返回 Top K 相关结果
- 响应速度快（≤ 3 秒）

**深度模式：**
- 先理解问题上下文，进行多轮检索
- 若知识库无结果或结果置信度低，自动触发联网搜索
- 联网搜索需用户配置搜索工具 API Key（Bing/Tavily/百度/Google）
- 若用户未配置搜索工具 API Key，深度模式不可选择，提示用户先配置
- 回答标注来源（蓝色：知识库，绿色：网络）
- 响应时间较长（≤ 10 秒）

**保存搜索结果：**
- 深度模式联网搜索完成后，用户可选择将搜索结果保存到"联网搜索知识库"
- 保存内容包括：问题、回答、搜索来源、保存时间
- 保存后可在知识库管理中查看和管理

**模型切换：**
- 用户在问答界面顶部配置栏选择模型
- 下拉框显示：系统默认模型 + 用户已配置的自定义模型
- 选择后立即生效，后续问答使用新模型

### FR-006 ReAct Agent 多步推理

对于复杂问题，Agent 自动编排多步推理流程，调用知识检索、工具和网络搜索，逐步得出答案。

### FR-007 Wiki 模式

Agent 驱动从原始文档自动生成结构化、相互链接的 Markdown Wiki 知识页面，并生成知识图谱。

### FR-008 文档在线编辑

用户在线编辑知识库中的文档内容，系统记录编辑历史并重新向量化。

### FR-009 多源数据同步

支持从飞书、Notion、钉钉等平台同步知识库数据。同步方式：

| 平台 | 同步方式 | 认证要求 | 说明 |
|------|----------|----------|------|
| 钉钉 | Webhook + API | 企业认证 | 支持全量/增量同步 |
| 飞书 | API | OAuth 授权 | 支持全量/增量同步 |
| Notion | API | API Key | 支持全量/增量同步 |

**同步规则：**
- 同步后自动生成「同步知识库」，显示来源平台标识
- 同步知识库的文档为只读，用户不可编辑或删除
- 管理员可手动触发全量同步，系统自动执行增量同步（默认每小时一次）
- 同步失败时记录错误日志，不影响已有数据

### FR-010 模型配置管理

用户可配置个人使用的 AI 模型，包括免费模型和自定义模型（需配置自己的 API Key）。管理员可配置系统级默认模型。

### FR-011 向量数据库配置

向量数据库为系统级基础设施，仅管理员可配置。普通用户无需感知底层引擎，创建知识库时系统自动使用管理员配置的向量数据库。

**管理员操作：**
- 配置向量数据库引擎类型（PostgresSQL pgvector / Elasticsearch / Milvus / Weaviate）
- 配置连接地址、认证信息
- 测试连接可用性
- 切换引擎（已有数据需迁移）

**用户视角：**
- 创建知识库时无需选择向量数据库
- 系统状态页显示当前使用的向量数据库引擎（只读）

### FR-012 搜索工具配置

用户若要使用深度模式，必须配置搜索工具 API Key。系统支持以下搜索工具：

| 搜索工具 | 说明 | API Key 获取方式 |
|----------|------|------------------|
| Bing | 微软搜索 | Azure 订阅 |
| Tavily | AI 搜索 | tavily.com 注册 |
| 百度 | 中文搜索 | 百度开放平台 |
| Google | 谷歌搜索 | Google Cloud 订阅 |

**配置规则：**
- 用户在配置中心添加搜索工具，填写 API Key
- 系统验证 API Key 有效性
- 深度模式联网搜索时，使用用户配置的搜索工具
- 若用户未配置任何搜索工具，深度模式不可用

### FR-013 第三方平台集成

管理员配置钉钉、飞书、Notion 等平台的集成参数，实现知识库自动同步。各平台认证要求参见 FR-009。集成配置为系统级设置，普通用户不可修改。

### FR-014 会话管理

用户查看、搜索、删除、重命名历史会话，支持在历史会话基础上继续提问。

### FR-015 后台管理

管理员进行用户管理、会话管理、知识库管理、日志管理和配置管理。

### FR-016 推荐问题生成

基于知识库内容自动生成推荐问题，帮助用户快速获取信息。

## 6. 业务规则

**BR-001** 用户总知识库容量不超过 10GB，单文件大小不超过 100MB。

**BR-002** 免费用户每月 AI 调用次数限制为 100 次，超出后需配置自定义模型。

**BR-003** 文档处理状态必须为"已就绪"才能参与检索。

**BR-004** 多租户数据完全隔离，不同租户的数据不可互相访问。

**BR-005** 超级管理员角色不可删除，不可修改权限。

**BR-006** 文档删除后保留 30 天，超过 30 天自动清理。

**BR-007** 会话记录保留 90 天，超过 90 天自动归档。

**BR-008** 深度模式必须配置搜索工具 API Key 才可使用，未配置时该模式不可选择。

**BR-009** 钉钉集成需企业认证，个人用户无法使用。飞书和 Notion 集成需管理员授权。

**BR-010** 同步知识库的文档为只读，用户不可手动上传、编辑或删除。同步知识库的存储不计入用户个人配额。

**BR-011** 向量数据库为系统级配置，仅管理员可修改。普通用户在创建知识库时无需选择向量数据库。

**BR-012** 联网搜索知识库由系统自动创建，用户可将深度模式中的搜索结果保存到此知识库。联网搜索知识库的存储计入用户个人配额。

## 7. 边界条件

**空数据处理：**
- 知识库为空时，提示用户上传文档
- 快速检索无结果时，建议用户切换到深度模式（需已配置搜索工具 API Key）
- 深度模式知识库无结果且联网搜索也无结果时，提示用户调整问题描述

**重复提交处理：**
- 文档上传支持幂等性，相同文件名覆盖旧文件
- 问答请求支持去重，1 秒内相同问题返回缓存结果
- 保存搜索结果支持幂等性，相同内容不重复保存

**网络异常处理：**
- 深度模式联网搜索失败时，降级为仅知识库检索
- 搜索工具 API Key 无效时，提示用户重新配置
- 搜索工具 API 调用超时时，提示用户稍后重试
- LLM 调用超时时，返回部分结果并提示

**权限不足处理：**
- 无权限访问时，返回 403 错误
- 操作他人资源时，返回权限不足提示

**数据超限处理：**
- 存储空间不足时，提示用户清理或扩容
- 调用次数超限时，提示用户等待或升级

## 8. 非功能需求

### 性能
- 快速检索响应时间 ≤ 3 秒（不含 LLM 生成时间）
- 深度模式响应时间 ≤ 10 秒（含联网搜索）
- 文档上传处理时间 ≤ 5 分钟（100MB 文件）
- 支持 100+ 并发用户
- 知识库检索召回率 ≥ 85%

### 安全
- 用户密码加密存储
- API 通信使用 HTTPS 加密
- 敏感配置加密存储
- 多租户数据完全隔离

### 日志记录
- 记录所有 API 请求日志
- 记录所有业务操作日志
- 记录所有错误日志
- 日志支持按时间、级别、模块筛选

## 9. 验收标准

### AC-001 用户注册
**Given** 用户访问注册页面
**When** 输入有效邮箱和密码
**Then** 系统创建账号并返回成功提示

### AC-002 知识库创建
**Given** 用户已登录且有编辑权限
**When** 输入知识库名称和描述
**Then** 系统创建知识库并返回知识库 ID

### AC-003 文档上传
**Given** 用户已登录且有编辑权限
**When** 上传 PDF 文件到知识库
**Then** 系统返回文档 ID，状态为"处理中"
**And** 处理完成后状态变为"已就绪"

### AC-004 智能问答 - 快速检索
**Given** 用户已登录，知识库已有文档
**When** 输入问题并选择"快速检索"模式
**Then** 系统返回知识库检索结果，响应时间 ≤ 3 秒

### AC-005 智能问答 - 深度模式（已配置搜索工具）
**Given** 用户已登录，知识库已有文档，已配置搜索工具 API Key
**When** 输入复杂问题并选择"深度模式"
**Then** 系统理解上下文进行检索，若知识库无结果则使用配置的搜索工具联网搜索，返回带来源标注的回答

### AC-006 智能问答 - 深度模式（未配置搜索工具）
**Given** 用户已登录，知识库已有文档，未配置搜索工具 API Key
**When** 查看检索模式选项
**Then** 深度模式不可选择，提示用户先配置搜索工具 API Key

### AC-007 保存搜索结果
**Given** 用户已完成深度模式联网搜索问答
**When** 用户选择保存搜索结果
**Then** 系统将搜索结果保存到"联网搜索知识库"，可在知识库管理中查看

### AC-008 权限控制
**Given** 用户角色为"观察者"
**When** 尝试上传文档
**Then** 系统返回权限不足错误

### AC-009 多租户隔离
**Given** 租户 A 和租户 B
**When** 租户 A 的用户查询知识库
**Then** 只能看到租户 A 的数据

### AC-010 存储配额
**Given** 用户已使用 9.5GB 存储
**When** 上传 1GB 文件
**Then** 系统返回空间不足错误

### AC-011 免费调用限制
**Given** 免费用户已使用 100 次调用
**When** 再次发起问答
**Then** 系统返回调用次数超限提示

## 10. 技术可行性说明

**需要关注的问题：**

1. **钉钉集成**：需要企业认证，建议先实现手动触发同步
2. **多租户隔离**：增加架构复杂度，建议初期使用 Schema 隔离
3. **免费调用限制**：需要分布式计数器，建议使用 Redis
4. **Wiki 模式**：实现难度较高，建议初期实现基础版本
5. **搜索工具集成**：不同搜索工具 API 差异大，需统一接口封装

**技术可行性确认：**

1. RAG 检索：成熟方案，Eino 框架已支持
2. ReAct Agent：Eino 框架支持 Agent 编排
3. 多模型支持：通过统一接口封装
4. 多格式文档解析：使用 Apache Tika 或类似工具
5. 搜索工具集成：需用户配置 API Key，统一接口封装
